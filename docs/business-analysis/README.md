# Phân tích nghiệp vụ

JACS Studio là ứng dụng Desktop hỗ trợ phân tích và biên tập video ngắn bằng AI,
đồng thời có cổng Admin quản lý bản quyền, sự cố và phát hành phiên bản.

Tài liệu trong thư mục này là nguồn tham chiếu cho Product Owner, BA, UI/UX,
Desktop, Backend và QA trước khi viết User Story.

- [product-scope.md](product-scope.md): mục tiêu, phạm vi và các phân hệ.
- [stakeholders-and-processes.md](stakeholders-and-processes.md): tác nhân và
  các luồng nghiệp vụ chính.
- [business-rules.md](business-rules.md): quy tắc License, telemetry và OTA.
- [ai-provider-and-rendering.md](ai-provider-and-rendering.md): cấu hình BYOK,
  provider AI, render local GPU/cloud/hybrid.
